# 3D Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 76-column ASCII panel logo with a Three.js relief that is traced from `logo.png`. A torch follows the pointer. ASCII glyphs appear only in the reveal and the ripple.

**Architecture:** A pure tracer (`logo-trace.ts`) turns the ink of the PNG into shapes with holes. A Three.js stage (`logo-stage.ts`, loaded with dynamic `import()`) extrudes one mesh per shape and lights them. It renders into a target, and a post pass swaps in glyph cells inside the storm band. A React shell (`LogoStage.tsx`) mounts the stage, and falls back to `AsciiImage` if WebGL fails.

**Tech Stack:** React 19, TanStack Start (SPA), three 0.187, Vite+ (`vp test` = Vitest, `vp check` = oxlint + oxfmt + tsc).

**Spec:** `docs/superpowers/specs/2026-11-23-logo-3d-design.md`

## Global Constraints

- `three` is imported only by `src/lib/logo-stage.ts`. That module is loaded only with `import("#/lib/logo-stage")`.
- No animation frame at rest. Frames run only while the torch, the tilt or a storm is still changing.
- DPR = `Math.min(devicePixelRatio || 1, 2)`.
- Colours come from the `--accent` and `--haze` tokens, through `rgbOf` in `three-ink.ts`. Read them again when `data-vibe` changes.
- Calm (`html[data-calm]`, `prefersReducedMotion()`) means: no tilt, no rise, no ripple. Hover lights the whole logo.
- Storm timing reuses `STORM_MS` (reveal 1100 ms, ripple 650 ms) and the 1400 ms rest between ripples, as `AsciiImage` uses today.
- GLSL in template strings uses `/* */` comments only.
- No commits unless the user asks.

## Review Focus

1. Ink touches the edge of the PNG → the contour must still close. Test: `traceShapes` on a mask that is inked along its border.
2. A transparent or empty PNG → no shapes, no crash, and the fallback ASCII shows. Test: `traceShapes` on an empty mask returns `[]`. `mountLogo` throws when there are no shapes.
3. An opaque PNG (no alpha) → the ink is the difference from the corner colour. Test in Task 1.
4. An island inside a hole (a dot in a ring) → 2 shapes, not 1. Test in Task 1.
5. Route change or HMR while the reveal runs → no leaked RAF and no leaked WebGL context. Covered by `dispose()` in Task 2, and checked in Task 4 by navigating between docs.

### Task 1: Ink tracer

**Files:**

- Create: `src/lib/logo-trace.ts`
- Test: `src/lib/logo-trace.test.ts`

**Interfaces:**

- Produces:
  - `type Point = [x: number, y: number]` (mask pixels, y down)
  - `interface InkMask { width: number; height: number; ink: Float32Array }` (0..1 per pixel)
  - `interface TracedShape { outer: Point[]; holes: Point[][] }`
  - `interface TraceOptions { threshold?: number /* 0.5 */; tolerance?: number /* 0.35 px */; minArea?: number /* 16 px² */ }`
  - `function maskFromRgba(data: ArrayLike<number>, width: number, height: number): InkMask`
  - `function traceShapes(mask: InkMask, options?: TraceOptions): TracedShape[]`
  - `function signedArea(points: Point[]): number` (positive = counter-clockwise on screen, y down)

- [ ] **Step 1: Write failing tests** (`describe("traceShapes")`, `describe("maskFromRgba")`). Build masks with a helper `paint(width, height, inside: (x, y) => boolean)`.
  - `two separate blobs give two shapes without holes`: two 10×10 squares → `length 2`, each `holes.length 0`.
  - `a ring gives one shape with one hole inside it`: disc r=20 minus disc r=10 → 1 shape, 1 hole. `Math.sign(signedArea(outer)) === -Math.sign(signedArea(hole))`. Every hole point lies within 12 px of the centre.
  - `an island inside a hole is its own shape`: the ring above plus a disc r=4 at the centre → 2 shapes.
  - `the outline follows a round edge`: disc r=30 → every outer point is within `0.35 + 0.75` px of radius 30. `|signedArea|` is within 2 % of π·30².
  - `ink that touches the edge of the image still closes`: a full 20×20 mask → 1 shape, `|area|` within 1 px² of 400 (the contour sits on the pixel-centre grid: 19×19 = 361 is also fine; assert `> 350`).
  - `a speck smaller than minArea is dropped`: a 3×3 square → `[]`.
  - `an empty mask gives nothing`: all zero → `[]`.
  - `maskFromRgba`: (a) cut-out → ink = alpha/255; (b) opaque white with black square → square ink ≈ 1, background ink ≈ 0; (c) opaque black with white square → the same.
- [ ] **Step 2: Run** `vp test src/lib/logo-trace.test.ts` → FAIL (module missing).
- [ ] **Step 3: Implement.** Pad the grid with one ring of zeros. Use marching squares with linear interpolation at `threshold`. Resolve saddle cells by the cell-centre average. Join the segments into closed loops by their edge keys. Drop loops with `|area| < minArea`. Simplify each loop as a closed polyline with Ramer–Douglas–Peucker at `tolerance`. Nesting depth = how many other loops contain one point of the loop (even-odd ray test). Even depth = outer; odd depth = hole of the smallest outer that contains it. Normalize the winding: outer positive, holes negative. `maskFromRgba`: if any alpha < 250 → alpha; otherwise `|lum − cornerLum| / max(cornerLum, 1 − cornerLum)`, where cornerLum is the mean of the 4 corners. Clamp to 0..1.
- [ ] **Step 4: Run** `vp test src/lib/logo-trace.test.ts` → PASS.

### Task 2: The stage, lit (no storm yet), wired into the panel

**Files:**

- Create: `src/lib/logo-stage.ts`, `src/components/LogoStage.tsx`
- Modify: `src/components/Panel.tsx:80-82`, `src/styles/panel.css` (logo section)

**Interfaces:**

- Consumes: `maskFromRgba`, `traceShapes` (Task 1). `rgbOf`, `approach` from `three-ink.ts`. `prefersReducedMotion`.
- Produces:
  - `interface LogoStageOptions { canvas: HTMLCanvasElement; host: HTMLElement; image: HTMLImageElement; onReady(): void }`. `host` receives pointer and focus events (the panel link).
  - `interface LogoStage { dispose(): void }`
  - `function mountLogo(options: LogoStageOptions): LogoStage`. It throws if WebGL is missing or there are no shapes.
  - `function LogoStage(props: { src: string; label: string; columns: number; host: RefObject<HTMLElement | null> }): JSX.Element`

- [ ] **Step 1: Stage scene.** Trace at 640 px on the long side (draw the image to a canvas, then `maskFromRgba` + `traceShapes`). The world is 1 unit across the logo width, centred. Build one `ExtrudeGeometry` per shape: depth 0.045, bevel thickness 0.012, size 0.006, 4 segments, curveSegments 1 (the polygons are already dense). Flip y. Use `MeshPhysicalMaterial` (colour = accent × 0.25, emissive = accent × 0.42 at rest, roughness 0.35, clearcoat 0.6). A `ShadowMaterial` ground plane (opacity 0.55) catches the shadows. The torch is a `PointLight` with shadows (map 1024, radius 6), 0.32 above the surface. Add a dim fixed key light from the top left, and a haze-coloured additive disc sprite on the ground under the torch. Use a `PerspectiveCamera` at fov 26, framed so the logo fills the canvas with a 6 % margin at the rest tilt (pitch −0.10 rad).
- [ ] **Step 2: Motion.** Use one damped target `{x, y, on}`, written by `pointermove`/`pointerleave` on `host`, normalized to the canvas rect cached by `ResizeObserver`. Torch position and intensity ease with `approach(…, 0.12, dt)`. Tilt: group yaw = x·0.16, pitch = −0.10 + y·0.10; camera x = −x·0.04 (opposing). `focus` → torch parked at centre, high and wide. Calm → no tilt; hover fades a uniform light over the whole logo. The RAF runs while any eased value is more than 1e-4 from its target, then stops. Pause on `visibilitychange`. `dt` is clamped to 1/30.
- [ ] **Step 3: Vibe + lifecycle.** A `MutationObserver` on `data-vibe`/`data-calm` re-reads the colours and redraws. `dispose()` cancels the RAF, disconnects the observers, aborts the listeners, disposes geometries, materials, targets and the renderer, and calls `renderer.forceContextLoss()`.
- [ ] **Step 4: Component + panel.** `LogoStage.tsx`: a wrapper `.logo3d` (aspect-ratio from the image), with a `canvas.logo3d__canvas` (`role="img"`, `aria-label`). Load the image, then `import("#/lib/logo-stage")`, then `mountLogo`. On any rejection, render `<AsciiImage src columns label beam storm />` instead. `Panel.tsx` renders `<LogoStage src={logoUrl} label={title} columns={LOGO_COLUMNS} host={logoRef} />`. CSS: canvas `display:block; width:100%; height:100%`, opacity 0 → 1 on `[data-ready]` with `var(--lit)`.
- [ ] **Step 5: Verify.** Run `vp check` → no errors. Run `vp dev`, then take a headless Chrome screenshot of `/content/<slug>` (Task 4 script). The relief shows; its silhouette matches `logo.png`.

### Task 3: Storm — rise reveal, ripple, ASCII band

**Files:**

- Modify: `src/lib/logo-stage.ts`, `src/lib/ascii-art.ts` (export the ramp)

**Interfaces:**

- Consumes: `STORM_MS`, `StormKind` from `glyph-storm.ts`. `SOLID_GLYPHS`.
- Produces: `export function glyphRamp(font: AsciiFont): { glyphs: string[]; ink: number[]; cellAspect: number } | null`. This renames the private `measureRamp` in `ascii-art.ts`; `imageToAscii` keeps using it.

- [ ] **Step 1: Post pass.** Render the scene into a `WebGLRenderTarget` (samples 4, size = drawing buffer). A full-screen quad samples it. Cell grid: `columns` cells across the logo width (76, the same density as today), with cell height = width / `cellAspect`. Glyph atlas: one row of `glyphRamp` glyphs, white on clear, drawn in the canvas's computed `--mono` at weight 700. Per cell: `band = storm band mask at the cell centre`. If band > 0: tone = luminance of the target at the cell centre, glyph index = ramp index of tone ± a per-frame scramble; colour = mix(accent, white, band) × tone, with a haze glow. Otherwise pass the crisp scene through.
- [ ] **Step 2: Reveal.** Per mesh, `rise = clamp((t·speed − dist(centre of mesh, logo centre)) / 0.25)`, spring-eased (overshoot about 8 %). `mesh.scale.z = rise`, and emissive is scaled by rise. The band is a ring at radius `t·speed` with a width of 0.12. It runs once per image, over `STORM_MS.reveal`.
- [ ] **Step 3: Ripple.** On `pointerenter` (not within 1400 ms of the last one, not calm, not during the reveal): origin = entry point. Ring radius = `t/STORM_MS.ripple · reach`. A per-mesh Z lift = `0.03·exp(−((d − r)/0.08)²)` (`mesh.position.z`). The band uses the same ring.
- [ ] **Step 4: Verify.** `vp check` and `vp test` → pass. Take screenshots at reveal t≈400 ms and ripple t≈250 ms: the glyph band is visible only in the ring, and the crisp relief shows outside it.
